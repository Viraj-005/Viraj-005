## About

I'm a freelance software engineer working out of Sri Lanka, currently at Sri Lanka Telecom (SLT). I studied Information Technology (BSc Hons) at Horizon Campus, and most of my work sits at the intersection of backend systems, data heavy dashboards, and the occasional AI/ML side project.

Day to day I build things in Python and FastAPI on the backend, React on the front end, and I spend a fair amount of time in PostgreSQL and Oracle databases, usually cleaning up or automating something that used to be done by hand. Lately I've also been getting into cybersecurity, working toward SOC analyst fundamentals through TryHackMe and hands on labs.

What I'm doing right now:

- Maintaining and extending a **Sales Incentive Calculation system** in production for a telecom client, handling slab based commission logic, PCR stage gating, and Oracle to PostgreSQL migration work
- Building a personal records and credential manager as a React Native mobile app, ported from a desktop project my brother built for university
- Studying for cybersecurity certifications and building out a home lab
